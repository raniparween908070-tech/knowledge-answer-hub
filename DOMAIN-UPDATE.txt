EASIEST WAY (run inside the project folder; use your real URL, no trailing slash)
------------------------------------------------------------------------------
macOS / Linux / Git Bash:
  grep -rl 'https://example.com' public | xargs sed -i.bak 's#https://example.com#https://YOUR-SITE.netlify.app#g' && find public -name '*.bak' -delete

Windows PowerShell:
  Get-ChildItem public -Recurse -Include *.html,*.txt,*.xml | ForEach-Object { (Get-Content $_.FullName -Raw -Encoding UTF8) -replace 'https://example.com','https://YOUR-SITE.netlify.app' | Set-Content $_.FullName -NoNewline -Encoding UTF8 }

Then check that nothing is left, and redeploy:
  grep -rn 'example.com' public   (only the contact-form placeholder  you@example.com  should remain - leave it)
  netlify deploy --build --prod

Note: the contact form's email placeholder (you@example.com) is intentional example text, not a domain placeholder. Do not change it.
